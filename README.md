# نظام إدارة الشركة

نظام متكامل لإدارة الشركة: الشفتات، التاسكات، طلبات تغيير الشفت، التبديلات، والمرتبات — بثلاثة أدوار:

| الدور | الصلاحيات |
|---|---|
| **عضو** | شفتاته وتأكيد انتهاء الشفت، تاسكاته، مرتبه وتفاصيله، طلب تغيير شفت (يذهب لمشرف قسمه) |
| **مشرف** | تحديد الشفتات (اليوم/الوقت لكل عضو)، تبديل الشفتات (مؤقت/دائم)، إضافة أعضاء، الموافقة على طلبات التغيير، مرتبه، أداء قسمه |
| **سوبر أدمن** | إدارة الأقسام (إضافة/حذف/تحديد المشرف)، إنشاء الأعضاء والمشرفين والترقية، تحديد المرتبات، إدخال حوافز وخصومات شهرية لكل عضو، متابعة الشفتات وأداء الجميع |

التقنية: **Next.js (React) + Firebase (Authentication + Firestore) + نشر على Vercel**

---

## أولاً: إنشاء مشروع Firebase (خطوة بخطوة)

1. ادخل على https://console.firebase.google.com وسجّل بجوجل، ثم **إضافة مشروع** وسمِّه مثل `hr-system` (أي اسم).
2. من القائمة الجانبية: **Authentication** ← تبويب **Sign-in method** ← فعّل **Email/Password** واحفظ.
3. من القائمة الجانبية: **Firestore Database** ← **إنشاء قاعدة بيانات** ← اختر الوضع **Production** ← منطقة قريبة (مثل `europe-west1` أو `me-central2`).
4. ضع قواعد Firestore (من تبويب Rules): الصق محتوى ملف `firestore.rules` المرفق — لأن النظام يعمل بالكامل عبر السيرفر.
5. من **Project settings** ⚙️: قسّم **Your apps** ← **Web** ← سجّل تطبيق ويب، وستحصل على متغيرات `apiKey` و `authDomain` و `projectId` وغيرها.
6. من نفس الصفحة: تبويب **Service accounts** ← **Generate new private key** — ستحمل ملف JSON.

## ثانياً: إعداد المتغيرات على جهازك

1. انسخ `.env.local.example` إلى `.env.local`.
2. ضع قيم المتغيرات الستة `NEXT_PUBLIC_FIREBASE_*` من خطوة (5).
3. افتح ملف JSON الذي نزلته وانسخ محتواه كاملاً في متغير `FIREBASE_SERVICE_ACCOUNT` — إن واجهت مشاكل مع الأسطر المتعددة، حوّله إلى Base64 ثم ضعه:
   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\key.json"))
   ```

## ثالثاً: التشغيل محلياً

```bash
npm install
npm run dev
```

افتح `http://localhost:3000/setup` — ستظهر صفحة **الإعداد الأولي** لإنشاء حساب السوبر أدمن (تظهر فقط قبل وجود أي مدير). ثم سجّل الدخول من `http://localhost:3000/login`.

## رابعاً: النشر على Vercel

1. ارفع الكود على GitHub (أو استخدم Vercel CLI).
2. في Vercel: **Add New Project** ← استورد المشروع ← في **Environment Variables** أضف نفس متغيرات `.env.local` السبعة (مع `FIREBASE_SERVICE_ACCOUNT` سطراً واحداً كاملاً).
3. **Deploy** — بعدها افتح `https://موقعك.vercel.app/setup` وأنشئ السوبر أدمن.

> ملاحظة أمان: قاعدة بيانات Firestore مقفولة للوصول المباشر، وجميع العمليات تمر عبر API خلف Vercel مع تحقق صارم من الدور، وأي حد يفتح `/setup` بعد إنشاء أول مدير يُحوَّل للدخول تلقائياً.

## طريقة العمل اليومية

1. **السوبر أدمن**: أنشئ الأقسام ← عيّن مشرف كل قسم ← أضف الأعضاء ← حدد المرتبات ← في نهاية كل شهر يضيف الحوافز/الخصومات لكل عضو.
2. **المشرف**: يحدد شفتات كل عضو من صفحة الشفتات، ويبدّل الشفتات (مؤقت = يوم واحد، دائم = كل الشفتات من تاريخ معين وسيطبق تلقائياً على أي شفت جديد)، ويراجع طلبات تغيير الشفت.
3. **العضو**: يفتح لوحة التحكم كل يوم، يرى شفتات اليوم ويؤكد انتهاءها، ينجز تاسكاته، ويطلب تغيير شفت عند الحاجة.
